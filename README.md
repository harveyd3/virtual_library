Library Manager
- 

Project Overview
-
A virtual library that holds the author's name, book's name,
and ISBN number of each book that is given to the library through the user's input.

Features
- 

    - Add a new book to the library
    - List all books in the library
    - Search for a book by title or author
    - Exit the program

Project Structure
-
Assignment 3
    
    -book.py
    -library_manager.py
    -README.md 
    -.gitignore
- book.py - Book class that stores the title, author, and ISBN of each book
- library_manager.py -The main program that holds the library menu
- README.md - Provide information about the project
- .gitignore - Ignores certain files and folders

Requirements
-
Python 3.14

How to Run
-
    1. Open a terminal
    2. Navigate to Assignment 3 project folder
    3. Run the library_manager.py file and run the program
    4. Follow menu options that are displayed
